## ❓ FAQ

<details>
<summary><b>Is MyTube safe to use?</b></summary>
<br>
Yes! MyTube is open source and based on NewPipe. The code is publicly available for anyone to review. It doesn't collect any personal data.
</details>

<details>
<summary><b>Why isn't this on the Play Store?</b></summary>
<br>
Apps that block ads and download videos from YouTube violate Google Play Store's terms of service, so we distribute it directly through GitHub.
</details>

<details>
<summary><b>How do I update the app?</b></summary>
<br>
Simply download the latest APK from the <a href="https://github.com/Arkrly/NewPipe-Custom-UI/releases">Releases page</a> and install it over the existing app. Your data will be preserved.
</details>

<details>
<summary><b>Can I import my YouTube subscriptions?</b></summary>
<br>
Yes! Go to Settings → Content → Import subscriptions, and follow the instructions to import from YouTube.
</details>
